Privacy & Data

Client-side web application

SBCODE vLLM Client operates within your browser, communicating directly with the configured vLLM endpoint.

Locally stored data

Your browser stores endpoint address, API key, model information, saved configurations, prompts, and conversations using localStorage.

No chat data transfer to SBCODE servers

During regular operation, we don't receive your API key, saved conversations, or vLLM responses.

vLLM/RunPod

Chat requests are handled by the configured service, which may process and retain data according to their policies. Be cautious about submitting sensitive information.

Website and Cloudflare

Your first request to this website is proxied through Cloudflare, potentially logging standard information like IP addresses for security purposes and performance optimization.

Subsequent chat requests you make to your configured vLLM/RunPod endpoint are not proxied by Cloudflare, ensuring that only your browser communicates directly with the endpoint.

Data clearance

Clearing browser data removes settings and conversations but does not delete data sent to the configured vLLM/RunPod endpoint.

Browser extensions warning

Using this service with broad permission browser extensions that can read local storage from visited websites could pose privacy risks and compromise API keys. Disable or delete your browser extensions.
